Astral prepares your first Bot when you open it. Connect a model, then choose a computer it may use. Chat platforms can be added later.

Desktop opens directly. Browser access to a Server requires a configured [web account](/docs/hosting/security/).

## 1. Connect a model

Choose your model service, enter its connection details, and save. Then select the model to use. Saving an API key and choosing a model are separate steps.

You can use a hosted API or your own compatible service. A custom endpoint must be reachable from the machine running **Astral Server**.

## 2. Choose a computer

Select an online computer or connect the server machine, a container, or another machine.

“Start using Astral” grants this Bot permission to read files and run commands on the selected computer and makes it the default for new sessions. You can adjust this later in the Bot's Computer access settings.

When using a browser, the local machine means the machine running the Server. To use the device running your browser, connect it separately.

## 3. Verify execution

Start a session and try:

> Identify the current computer and working directory, then list its files. Do not modify anything yet.

Check the computer name in the execution record and the returned results before working on a real project.

## Continue setting up

- Add models or web search in [Models and search](/docs/usage/models/).
- [Connect more computers](/docs/computers/connect/) and grant access individually.
- [Connect a chat platform](/docs/chat/overview/) for private or group conversations.

Simple settings save automatically. Multi-field connection settings require “Save connection” in that section. Resolve any error shown there; there is no global Save button.
