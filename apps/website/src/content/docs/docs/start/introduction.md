---
title: "Meet Astral"
description: "Let a Bot use your computers to complete work in one continuous session."
---

Astral is a personal agent that runs on your own devices. Give a Bot a task and it can read files and run commands on computers you have authorized, then return results in Astral or a connected chat.

One session can span several computers: read a project on your laptop, test it on a Linux server, and build it on Windows. The task context stays in that session; each operation runs on a specific computer.

## Complete your first task

1. [Get and run Astral](/docs/start/get-astral/).
2. [Connect a model and choose a computer](/docs/start/first-steps/).
3. Try something easy to verify: “List the files in this directory and explain how to start this project.”

Chat platforms are optional. Once the model and computer work in Astral, [connect Telegram, QQ, Weixin, or Feishu](/docs/chat/overview/).

## Three useful distinctions

| Object | Purpose |
| --- | --- |
| Bot | Holds model choices, persona, computer permissions, and chat accounts. |
| Session | Holds the messages and context for ongoing work. A Bot can have several sessions. |
| Computer | Provides files and command execution on the server machine, a remote machine, or a container. |

Connecting a computer does not grant every Bot access to it. Switching computers keeps session context but does not synchronize files or move existing processes.
