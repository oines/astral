---
title: "群聊协作"
description: "让多个成员在同一个聊天中提出任务、补充信息并接收结果。"
---

Telegram、QQ 和飞书支持群聊，微信目前支持私聊。群内成员共同使用该聊天的会话，可以交代任务、补充资料和接收结果。

**公开群聊建议使用专用 Bot 和独立容器，强烈不建议直接授权日常电脑。** 群内任何成员都可以提出请求，任务使用 Bot 已获准的电脑和平台权限。接入前阅读[安全使用 Astral](/zh-cn/docs/start/safe-use/)。

## 从明确提及开始

1. 把平台 Bot 加入目标群，并完成[聊天授权](/zh-cn/docs/chat/overview/)。
2. 在群里 `@Bot` 交代任务，或回复一条 Bot 已发送的消息。
3. 其他成员继续补充材料。Bot 工作时，新收到的消息会进入后续模型步骤；空闲时，提及或回复它即可唤醒。
4. 要求 Bot 把文件或结论发回当前群，并检查实际发送结果。

例如，第一位成员让它从指定电脑整理周报，第二位成员补充本周完成的事项，然后 Bot 在同一会话中生成并发送文档。

## 普通消息与主动参与

主动参与默认关闭。对于已经接入的群，Bot 收到的普通消息仍会进入会话上下文；Bot 空闲时，不会仅因为普通消息到来就启动任务。

Bot 工作时，会在后续步骤中读取新消息，判断它们与当前任务的关系。私聊也遵循这个规则。

按群开启主动参与后，Astral 会在讨论短暂停顿时判断是否需要唤醒空闲的 Bot：连续 10 秒没有新消息，或从第一条待判断消息起累计 60 秒。它会按讨论内容决定参与或保持安静。直接提及、回复 Bot 或平台支持的戳 Bot，以及私聊消息，会直接唤醒空闲的 Bot。



## 能看到多少上下文

Astral 只能使用平台实际交付的消息。Telegram 隐私模式、QQ 获批的消息权限、飞书应用权限都可能限制普通群消息。主动参与开关不会扩大平台权限，也不会自动获取加入群之前的全部历史。

群里的成员共享该聊天会话。通过这个 Bot 发起的任务使用 **Bot 已获准的电脑权限**；成员不会因为发送消息而得到独立的操作系统账号或独立目录。

## 把不同群分开

不同聊天使用不同会话。同一 Bot 仍可通过内置 API 查询其他非私密会话，电脑文件也可能共享。私人工作可[设为私密](/zh-cn/docs/usage/conversations/#私密会话)；信任范围不同的群建议使用不同 Bot 和执行环境。

Telegram 论坛 Topic 可以分别接入。飞书线程目前归入父聊天。

如果想更换某个群使用的会话，在账号的已接入聊天中修改绑定；原有历史会保留，正在运行的任务会停止。
