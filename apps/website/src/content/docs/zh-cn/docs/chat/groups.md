接入群聊后，群成员可以一起推进同一件事：一个人让 Bot 整理会议记录，另一个人接着补充改动，Bot 会在同一个 Astral 会话里持续处理，把结果发回群里。

Telegram、QQ 和飞书支持群聊（微信目前仅支持私聊）。先按[接入聊天](/zh-cn/docs/chat/overview/)连好账号并添加目标群。

:::caution[群成员共享同一套电脑与账号权限]
一个群共用一个会话和 Bot 已获准的电脑、聊天账号权限（不会按发言人做隔离）。公开群请务必准备专用 Bot 与独立容器，详见[权限与隐私](/zh-cn/docs/start/safe-use/#公开群聊使用独立环境)。
:::

## 发起任务与中途补充

- **唤起 Bot**：在群里用聊天软件的 `@` 功能真正提及 Bot，或直接回复它发过的消息：

> @Bot 把下面的会议记录整理成“决定事项”和“待办事项”，完成后发回这个群。

- **运行中补充**：默认情况下，群成员可以接着发“上线日期改成下周三”，Bot 会在后续处理任务时读到。如果这个群关闭了**参考群聊消息**，请在补充时 @ Bot 或回复它的消息。

:::tip[Telegram 群聊先测“回复”]
Telegram 默认隐私模式可能限制 Bot 收到普通群消息，首次测试先直接回复 Bot 的消息，详见 [Telegram 群聊设置](/zh-cn/docs/chat/telegram/#让-bot-参与群聊)。
:::

## 选择 Bot 要参考哪些群消息

在**设置 → Bot** 中打开该 Bot 的平台账号，找到**已接入聊天**。每个群、每个已接入的 Telegram 群话题都有自己的**参考群聊消息**开关。

希望 Bot 跟得上群里的讨论时，保持默认开启。平台送达的普通消息可以成为当前任务和以后回复的上下文。还可以选择 Bot 空闲时何时开口：

- **被提及时回复**（默认）：群成员 @ Bot、回复它的消息，或在支持的平台上戳它，都可以唤起 Bot。
- **主动参与讨论**：除了直接唤起，群里安静 10 秒或距第一条待判断的消息满 60 秒时，Bot 也会判断是否加入讨论。

希望群成员明确喊 Bot 才处理消息时，关闭**参考群聊消息**。此后普通群消息、表情回应等仍会归档，只是不会自动加入会话。@ Bot、回复或戳 Bot，以及 Bot 自己发的消息仍会进入会话。之前的会话上下文会保留。重新开启后，新消息按原先选择的回复方式处理，关闭期间的闲聊留在归档中，不会补进会话。

Bot 只能收到平台允许送达的消息。需要它参考接入前的资料时，在群里 @ 它或回复它的消息，把资料再发一次。

## 多群隔离与私人工作

- **每个群独立会话**：不同群（以及 Telegram 论坛的不同话题）各自拥有独立会话；飞书线程目前归入所属父聊天。
- **和私人工作分开**：同一 Bot 可查其他非私密会话，也可能共用同一台电脑的目录。私人工作建议单独建 Bot，或至少[设为私密会话](/zh-cn/docs/usage/conversations/#私密会话)。更换群绑定的会话时，两边运行中的任务都会先停止并保留各自历史。
