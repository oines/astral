---
title: "接入聊天"
description: "从 Telegram、QQ、微信或飞书交代任务，并在原聊天收到结果。"
---

接入后，你可以在常用的聊天软件里交代任务，让 Astral 使用已配置的模型和电脑完成工作，再把结论或文件发回来。每个接入的聊天对应一个 Astral 会话，任务和后续补充会留在一起。

先在 Astral 内[完成一次任务](/zh-cn/docs/start/first-steps/)，再接入聊天。收发消息期间 Astral 必须保持运行；需要关闭自己的电脑后仍可使用，见[运行方式](/zh-cn/docs/hosting/architecture/)。

## 选择接入方式

从 **设置 → Bot → 目标 Bot → 连接平台** 进入，按你要用的账号阅读对应指南：

| 你准备使用的账号 | 指南 |
| --- | --- |
| Telegram 机器人 | [连接 Telegram](/zh-cn/docs/chat/telegram/)，通过 BotFather 取得 Token |
| 普通 QQ 号，或 QQ 开放平台机器人 | [连接 QQ](/zh-cn/docs/chat/qq/)，分别使用 NapCat 或官方 Bot 接入 |
| 微信扫码授权的 Bot | [连接微信](/zh-cn/docs/chat/weixin/)，目前支持私聊 |
| 飞书企业自建应用机器人 | [连接飞书](/zh-cn/docs/chat/feishu/)，需要应用权限、发布和事件配置 |

一个 Astral Bot 可以连接多个平台账号，每个账号分别管理自己的聊天。群内成员可以让 Bot 使用它已获准的电脑和平台权限；公开群请使用专用 Bot 和[独立执行环境](/zh-cn/docs/start/safe-use/)。

## 账号连接后，还要选择聊天

新账号默认 **仅指定的聊天**，列表为空。平台指南会说明如何发现目标聊天，或取得它的 Chat ID；随后在账号的 **已接入聊天** 中添加它。

添加时选择新会话，就从新的工作上下文开始。选择已有会话，则沿用同一 Bot 下那段工作的上下文；它必须尚未绑定其他聊天。接入多人群前，确认已有上下文适合这个群使用。

也可以允许 **机器人能访问的全部聊天**。此后，新的私聊消息，或群里首次提及、回复 Bot 的消息，会自动建立会话。这个选择扩大了 Bot 可访问的聊天范围；只服务少数聊天时，保留指定模式。

## 用一条新消息确认接通

完成添加后，回到原平台，**重新发送**：

> 请在这个聊天里回复“连接成功”，并告诉我你当前使用哪台电脑。

群里真正提及 Bot，或回复它已发出的消息。发现聊天用的旧消息不会在授权后自动成为任务。

在 Astral 对应会话中能看到处理过程，在原聊天收到回复，才完成了这次验证。接着可发一张图片或小文件，请 Bot 读取并发回来。希望收到结论或文件时说清楚“发回这个聊天”。Bot 直接输出的文字只显示在 Astral 网页，群聊或私聊中的用户看不到；它需要调用 `send_message` 才能把回复发到聊天。

处理私聊、提及或回复 Bot 等直接触发的消息时，如果 Bot 正常结束却没有调用发送工具，Astral 会再提醒它一次。提醒后它仍可选择不回复，Astral 不会自动把过程文字发到聊天。这次补提醒不用于主动参与讨论；发送工具已经调用但失败或结果未确认时，也不会因此再提醒或重发。

## 日常使用中需要知道的事

- **群里何时回复**：默认被提及或被回复时处理；普通讨论的参与方式见[群聊协作](/zh-cn/docs/chat/groups/)。
- **只移除一个聊天**：先使用“仅指定的聊天”。从全部模式切回时，已接入聊天及设置会保留。
- **暂停账号**：关闭“启用账号”会保留历史并停止接收；已开始的电脑任务仍需在会话中单独停止。
- **更换会话**：会停止原会话和目标会话的运行，保留两边历史；已经接受的发送仍发往原目的地。

如果模型额度不足、凭据失效或没有访问权限，Astral 会在对应会话保留错误并暂停处理，仍继续接收和归档平台消息。恢复额度或修正凭据后，在 Astral 打开该会话发送新输入重试；成功更换为可用模型，也会重新尝试处理等待中的消息。限流、服务暂时不可用和网络故障会间隔重试；不断发送新消息不会加快重试。

如果会话提示摘要输入超出模型上下文窗口，处理也会暂停，等待中的消息会保留。需要改用能容纳该摘要输入的模型或修正模型窗口配置，再重试；服务恢复或继续发送聊天消息不会消除这个限制。成功更换会话模型，或修正模型窗口、连接配置后，会重新尝试处理；成功压缩并通过预算检查后继续运行。

查询成员、管理群文件等任务可以直接交给 Bot。只有需要自定义调用时，才需要[平台 API 参考](/zh-cn/docs/chat/platform-api/)。
