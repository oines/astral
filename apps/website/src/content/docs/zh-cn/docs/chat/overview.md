---
title: "接入聊天"
description: "从聊天平台交代任务，让 Bot 使用电脑并把结果发回来。"
---

在 Telegram、QQ、微信或飞书里交代任务，让 Astral 使用你的电脑完成工作，再把结果发回聊天。每个接入的聊天对应独立的 Astral 会话。

## 连接之前

先完成 Bot 的[模型和电脑配置](/zh-cn/docs/start/first-steps/)，并在 Astral 内验证一次任务。再准备要连接的平台账号。

| 平台 | 接入方式 | 当前聊天范围 |
| --- | --- | --- |
| [Telegram](/zh-cn/docs/chat/telegram/) | Bot Token | 私聊、群、论坛 Topic、频道 |
| [QQ](/zh-cn/docs/chat/qq/) | 官方 Bot 或 NapCat | 私聊、群聊；标识和能力因方式而异 |
| [微信](/zh-cn/docs/chat/weixin/) | ClawBot / iLink 扫码 | 私聊 |
| [飞书](/zh-cn/docs/chat/feishu/) | 企业自建应用 Bot | 私聊、群聊 |

## 1. 连接平台账号

打开 **设置 → Bot → 目标 Bot → 连接平台**，选择平台并完成凭据填写或扫码。平台下会保留账号列表，每个账号独立管理自己的聊天。

连接成功表示凭据和连接通过验证，不代表 Bot 已获准响应任何聊天。

## 2. 决定哪些聊天可用

新账号默认使用“仅指定的聊天”，列表为空。可以添加或选择已经发现的聊天，核对 Chat ID，需要时填写 Telegram Topic ID，然后建立会话绑定。

也可以选择“机器人能访问的全部聊天”。此时收到私聊消息，或群里首次提及、回复 Bot 时，会自动建立会话。平台未交付给 Bot 的聊天与消息不会因此变得可见。

切回“仅指定的聊天”会保留已接入聊天和它们的设置；若要单独移除某个聊天，先使用这个模式。

## 3. 选择会话并验证

添加聊天时，可以新建会话，或选择同一 Bot 下尚未绑定的会话。发送一个小任务，例如“查看你当前可以使用哪些电脑”，确认 Astral 收到消息并在原聊天回复。

会话也可在 Astral 中打开，查看消息、工具执行和文件。结果需要显式发送才会出现在外部聊天；Web 中的每段回复不会自动逐条转发。

## Bot 如何理解当前聊天

绑定聊天后，Astral 会在模型的系统提示中统一说明当前平台、账号连接、聊天标识、类型、名称和可选话题。信息不变时这段说明保持一致，聊天改名会在下一次新的模型请求中更新。每条消息只保留自己的来源、身份、发送者、时间，以及引用、附件或通知内容，不再重复整段聊天资料。

普通未绑定的 Web 会话不增加这段聊天说明。解绑、更换绑定或分支会话会保留已有历史的来源；历史消息不会因此变成新聊天的消息，已经准备好的请求也不会改写。是否唤醒 Bot 和何时读取新消息仍遵循原有[群聊规则](/zh-cn/docs/chat/groups/)。

## 更换绑定或暂停接收

更换 Session 会停止原会话和目标会话的运行，保留两边历史。已经接受的发送仍归属于原来的目的地，不会被重定向到新聊天。

临时停用时，关闭“启用账号”即可保留历史。群里怎样触发任务、何时主动参与，见[群聊协作](/zh-cn/docs/chat/groups/)。
