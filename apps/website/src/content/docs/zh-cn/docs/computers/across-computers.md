---
title: "跨电脑工作"
description: "在同一会话里分配多台电脑的工作，避免弄混文件和执行位置。"
---

同一个会话可以用多台电脑完成任务，之前的讨论和执行记录会保留。适合需要不同环境的工作，例如在数据服务器上计算，再回到办公室电脑制作报告。

需要提前准备的是各台电脑上的文件和工具。切换电脑不会自动同步它们。

## 交代机器分工

先[连接所需电脑并授权给 Bot](/zh-cn/docs/computers/connect/)，确认它们在线。使用容易辨认的名称，例如“办公室电脑”和“数据服务器”，再在任务中明确分工：

> 在数据服务器分析 `/home/mei/data/sales.csv`，生成本月销售汇总。然后把汇总结果放到办公室电脑的报告目录，制作图表。切换前先确认文件传输方式；不要假设两台电脑有相同目录。

会话空闲时，你可以在输入区选择当前电脑。Bot 也可以在执行任务时切换到已获准的电脑。需要核实时，让它报告本次操作所在的电脑和完整路径，并查看执行记录。

## 哪些内容会保留

消息、任务说明和执行记录始终留在同一个会话中。已经生成的文件链接仍然指向原来的电脑：服务器上生成的文件，不会因为当前选中办公室电脑而改变位置。

已经在旧电脑启动的进程也留在那台机器上。切换本身不会停止它或把它迁走；它可能继续运行，直到结束、被停止或连接中断。切换后仍要关注旧电脑上尚未完成的工作。

## 哪些内容不会自动迁移

项目文件、已安装软件、环境变量、登录状态和运行中的进程都不会随会话迁移。需要相同资料时，明确要求 Bot 使用可用的文件传输方式；代码项目也可以使用已有 Git 仓库。传输前确认目标位置和访问权限。

两台电脑上的相同路径可能保存完全不同的内容。第一次在新电脑执行时，先确认文件是否存在、所需软件是否可用，再继续任务。只改变工作目录也不会移动之前生成的结果。

如果来源电脑离线，仍能阅读会话历史；读取那台电脑上的原文件或操作进程，需要恢复连接。下载或备份重要结果，请看[文件与结果](/zh-cn/docs/usage/files/)。
