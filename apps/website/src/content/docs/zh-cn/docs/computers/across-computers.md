---
title: "跨电脑工作"
description: "在同一个会话中使用多台电脑，同时保留任务上下文。"
---

会话保存任务上下文，电脑提供执行环境。切换电脑后，先前的消息和执行记录仍在同一个 Session 中。

## 交代机器分工

先为 Bot 授权需要使用的电脑，并确认它们在线。给机器起容易区分的名称，例如“开发 Mac”“Linux 测试机”“Windows 构建机”。

然后在一个会话中说明任务和分工：

> 在开发 Mac 上阅读这个项目，使用 Linux 测试机运行测试，再到 Windows 构建机生成 Windows 版本。缺少代码或依赖时先告诉我。

你可以选择会话当前使用的电脑，Bot 也可以在任务中切换到它获准使用的电脑。查看每次执行所属的电脑，而不要只根据聊天窗口判断文件在哪里。

## 哪些内容会保留

- 已有消息、任务上下文和工具执行记录。
- 已经生成的文件链接及其来源电脑。
- 原来电脑上已经启动的进程，直到它自己结束、被停止或电脑离线。

## 哪些内容不会自动迁移

项目文件、依赖、环境变量、登录状态和后台进程不会随着会话切换而复制。新电脑需要有对应的代码和工具；可以明确让 Bot 使用 Git、文件传输或其他已有方式准备环境。

同名路径在两台机器上可能是完全不同的目录。切换工作目录也只会改变后续操作的位置，不会移动之前生成的文件。

来源电脑离线时，历史仍可阅读，但实时读取文件或操作进程需要重新连接该电脑。
