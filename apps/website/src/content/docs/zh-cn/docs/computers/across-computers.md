一个会话可以调度多台已授权的电脑：例如先在 Linux 数据服务器上跑脚本算结果，再切回办公室电脑生成图表和报告，整个过程和结论都留在同一段对话里。

## 给不同电脑分工

先[连接好所需电脑并授权给同一个 Bot](/zh-cn/docs/computers/connect/)，给机器起容易区分的名字（如“数据服务器”“办公室电脑”），然后在任务里直接写清分工：

> 在数据服务器上分析 `/home/mei/data/sales.csv`，把本月销售汇总保存为 `summary.csv`。将它复制到办公室电脑已有的 `reports` 目录，再用这份文件做图表。

会话空闲时你可以在输入区手动切电脑；执行过程中 Bot 也会按任务需要自动切换到它获准使用的其他电脑。想核实时，直接让它报出电脑名和完整路径，或展开执行记录查看。

## 切换电脑时：什么会留下，什么不会搬家

| 项目 | 切换电脑后会怎样 |
| --- | --- |
| **会话消息与执行记录** | 全部留在同一个会话中，上下文无缝延续。 |
| **旧消息里的文件链接** | 依然指向生成它的那台电脑，不会跟着切换改变位置。 |
| **正在运行的进程** | 留在启动它的那台电脑上继续跑（直到结束、被手动停掉或掉线），切换不会停止或迁移它。 |
| **文件、软件、环境变量、登录态** | 全部留在各自电脑上，**不会自动同步**。跨机器用同一份资料时，请明确让 Bot 传输文件或通过 Git 同步。 |

:::note[同名路径不等于同一份文件]
两台电脑上路径长得一样，内容可能完全不同；第一次在新电脑动手前先确认文件和工具是否存在。若来源电脑离线，历史记录仍可阅读，但读取原文件或操作进程需要等它恢复上线。需要长期保留的结果请[下载或备份](/zh-cn/docs/usage/files/)。
:::
