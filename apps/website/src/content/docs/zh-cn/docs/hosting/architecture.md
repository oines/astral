Astral Server 保存 Bot、会话、模型连接和聊天平台账号，并协调任务。电脑负责实际的文件操作和命令执行。两者可以运行在同一台机器，也可以分开。

## 从 Desktop 开始

Desktop 在本机管理 Server 和本机电脑连接，适合先在自己的电脑上使用。打开应用即可进入，不需要先创建网页登录账户。

如果任务依赖这台机器持续工作，应确保它保持运行且不会休眠；普通关闭窗口与彻底退出应用的行为取决于桌面偏好中的后台运行设置。

## 在固定机器上运行 Server

希望从不同设备访问同一套 Bot、保持聊天连接持续在线时，可以把 Server 放在长期运行的机器上，再通过浏览器访问。

浏览器只是操作界面，不会把浏览器所在设备自动注册为电脑。要让 Bot 操作你的笔记本，需要把笔记本作为电脑接入这个 Server。

Server 进程需要能访问所选模型、搜索服务和聊天平台；每台电脑需要能主动访问 Server。

## 选择执行环境

| 环境 | 适合的用途 |
| --- | --- |
| 服务所在电脑 | 使用 Server 机器上的文件与工具 |
| 远程电脑 | 使用其他操作系统、硬件或已有项目环境 |
| 容器电脑 | 为任务准备独立、持久的环境 |

一个 Session 可以在获准电脑之间切换。文件和进程仍各自留在执行的电脑上。

## 内置能力如何调用

Harness 负责推进会话和工具执行。Bot 通过文件、命令等基础工具使用电脑；历史查询、计划任务、聊天和文件管理通过内置 API 按需发现和调用。你可以直接交代任务，Bot 会读取所需接口的说明。

Astral 保持稳定的上下文前缀，环境发生变化时再追加更新，帮助连续工作复用模型服务的缓存。

准备自行部署时，继续阅读[运行 Server](/zh-cn/docs/hosting/server/)与[登录与安全](/zh-cn/docs/hosting/security/)。为群聊安排电脑时，先阅读[安全使用 Astral](/zh-cn/docs/start/safe-use/)。
