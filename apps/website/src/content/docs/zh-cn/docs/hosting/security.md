通过浏览器访问 Astral 需要登录管理员账户。该账户可管理全部 Bot、会话（含私密会话）与电脑，仅限可信管理员使用。桌面应用本机打开无需登录，仅在要通过浏览器访问时配置。

## 1. 设置网页登录

- **官方 Linux 安装器部署的 Server**：安装时已设置好用户名和密码，直接登录即可。
- **桌面版**：在 **设置 → 安全与访问 → 网页登录** 中设置用户名与密码。
- **独立 Server 尚未设置登录**：以运行 Astral 的系统账号登录服务器终端执行（把 `admin` 换成你的用户名；自定义数据目录加 `--data /你的/server/数据目录`）：

```sh
astral auth setup --username admin
```

## 2. 开启两步验证与保存恢复码

在 **设置 → 安全与访问 → 登录保护** 中添加二次验证（支持添加多种作为备份）：

| 验证方式 | 准备条件 |
| --- | --- |
| **验证器动态码** | 手机验证器 App（TOTP） |
| **通行密钥（Passkey）** | 实际 [HTTPS 域名地址](/zh-cn/docs/hosting/server/#通过-https-反向代理访问) 与支持 Passkey 的设备/浏览器（Passkey 绑定域名，换域名需重新添加） |

:::tip[开启后立刻保存恢复码]
在安全设置里生成并离线保存**恢复码**，防止手机丢失导致锁死。每个恢复码仅用一次，重新生成会使旧码失效。可在**已登录设备**随时踢出陌生会话（“退出所有设备”也会退出当前浏览器）。
:::

## 无法登录时恢复

| 情况 | 怎么处理 |
| --- | --- |
| 忘记密码 | 按下方命令重置账户（Astral 无邮件找回） |
| 验证器 / Passkey 不可用 | 先用恢复码登录；没有恢复码则重置账户 |
| 改完用户名或密码回到登录页 | 用新账号密码重新登录 |
| 网页打不开或提示主机名受限 | 看[排查问题](/zh-cn/docs/hosting/troubleshooting/#网页打不开或无法登录)或下方**主机名限制** |

能打开桌面版时，直接从桌面版安全设置重置。独立 Server 则登录服务器终端，以运行 Astral 的系统账号执行：

```sh
astral auth reset --username admin
```

:::caution[重置账户的影响]
重置会移除原有验证器与 Passkey，并退出全部已登录网页会话；随后用新密码登录并重新绑定验证方式。所有 Bot、会话历史和已连接电脑都会保留。
:::

## 主机名限制

希望只允许通过指定域名或 IP 打开管理页，在 **设置 → 安全与访问** 打开**限制访问主机名**，填入纯域名或 IP（例如 `https://astral.example.com:8443` 只填 `astral.example.com`，不带协议、端口、路径或 `*`），点击**保存主机名设置**。务必保留当前正在使用的地址。

若误改配置遇到 `403 unrecognized management host`，SSH 登录服务器查看或临时关闭限制（服务运行时立即生效，不删原名单与登录保护；自定义目录加 `--data`）：

```sh
astral config hostnames show
astral config hostnames disable
```

若提示限制由启动参数或环境变量控制，按提示修改服务配置并重启。想控制 Bot 能动哪些电脑与文件，见[权限与隐私](/zh-cn/docs/start/safe-use/)。
