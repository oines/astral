---
title: "登录与账户保护"
description: "设置网页登录、增加验证方式，或找回无法登录的 Astral。"
---

通过浏览器使用 Astral 时，需要登录管理员账户。这个账户能够管理所有 Bot、会话和电脑，包括私密会话，请只交给可信的管理者使用。

桌面应用打开后可以直接使用；需要从浏览器访问它时，再设置网页登录。

## 设置网页登录

**通过官方 Linux 安装器安装的 Server**，已经在安装过程中设置过用户名和密码，可以直接登录。

**使用桌面版**时，打开 **设置 → 安全与访问 → 网页登录**，设置用户名和密码。

如果网页提示“尚未设置登录”，而你使用的是独立 Server，请登录服务器终端，以运行 Astral 的系统账号执行：

```sh
astral auth setup --username admin
```

可以把 `admin` 换成自己希望使用的用户名。按提示输入密码并确认，然后回到网页登录。密码输入时不会显示字符。

命令会自动寻找已有安装。有多个安装时，按终端提示选择；手动部署使用了自定义数据目录时，添加 `--data /你的/server/数据目录`，与启动 Server 时的 `--data` 相同。

## 给登录增加一步验证

在 **设置 → 安全与访问 → 登录保护** 中添加一种验证方式：

| 方式 | 需要准备什么 |
| --- | --- |
| 验证器动态码 | 手机上的验证器 App，用于生成登录验证码 |
| 通行密钥（Passkey） | 实际 HTTPS 网页，以及支持通行密钥的浏览器或设备 |

添加并确认后，密码登录会要求再完成一步验证。可以添加多种方式，方便某个设备不可用时换一种。

Passkey 绑定添加时使用的域名。请通过同一个 HTTPS 地址登录；更换域名后，需要在新地址添加通行密钥。桌面内置页面无法直接配置时，先在浏览器打开自己的 [HTTPS 入口](/zh-cn/docs/hosting/server/#通过-https-反向代理访问)。

## 保存恢复码与管理登录

启用登录保护后，在安全设置中生成并保存恢复码。手机丢失或验证器不可用时，可以使用恢复码登录。每个恢复码只能用一次；重新生成后，旧码会失效。

在**已登录设备**中，可以让某个浏览器或命令行退出登录。不认识的登录应及时移除；使用“退出所有设备”会同时退出当前浏览器。

## 无法登录时恢复

先根据遇到的情况处理：

| 看到的情况 | 下一步 |
| --- | --- |
| 忘记密码 | 按下方步骤重置账户 |
| 验证器或 Passkey 不能使用 | 先尝试已保存的恢复码；没有可用方式时重置账户 |
| 修改用户名或密码后回到登录页 | 使用刚设置的新账户信息登录 |
| 网页根本打不开，或显示主机名不被允许 | 查看[网页连接排查](/zh-cn/docs/hosting/troubleshooting/#网页打不开或无法登录)或下方主机名限制 |

仍能打开桌面应用时，可以从它的安全设置恢复网页登录。使用独立 Server 时，在服务器终端以运行 Astral 的系统账号执行：

```sh
astral auth reset --username admin
```

把 `admin` 换成重置后希望使用的用户名，按提示输入新密码。自定义安装需要时添加 `--data /你的/server/数据目录`。

**重置会移除原来的验证器、Passkey，并退出已有网页登录。** 之后使用新用户名和密码登录，再重新添加验证方式。Bot、历史和已连接电脑会保留。Astral 没有邮件找回密码流程。

## 主机名限制

如果只希望通过指定域名或 IP 打开管理网页，可以在 **设置 → 安全与访问** 开启**限制访问主机名**，填写允许的地址，点击**保存主机名设置**。

例如，网址是 `https://astral.example.com:8443` 时，填写 `astral.example.com`。列表只填写域名或 IP，不包含协议、端口、路径或 `*`。保留当前正在使用的域名或 IP，避免把自己的入口删掉。

新安装的 Server 默认关闭这项限制；开启后，网页登录仍然需要账户验证。

如果改配置后看到 `403 unrecognized management host`，通过 SSH 登录服务器，先检查：

```sh
astral config hostnames show
```

需要恢复网页访问时，关闭主机名限制：

```sh
astral config hostnames disable
```

此操作保留原名单和登录保护。服务运行时立即生效，服务停止时在下次启动生效。若命令指出限制由启动参数或环境变量控制，按提示修改相应服务配置并重启；自定义目录可添加 `--data /你的/server/数据目录`。

需要限制 Bot 能使用哪些电脑和文件，继续阅读[权限与安全使用](/zh-cn/docs/start/safe-use/)。
