Desktop 使用自己的本机访问身份，打开即可使用。浏览器和命令行使用网页登录账户；该账户可以管理全部 Bot、会话和电脑，包括私密会话。请只由可信的管理者使用。电脑授权和群聊使用建议见[安全使用 Astral](/zh-cn/docs/start/safe-use/)。

## 设置网页登录

Desktop 用户可在 **设置 → 安全与访问** 中设置用户名和密码。无桌面环境时，在 Server 所在机器运行：

```sh
astral auth setup --data /path/to/server --username admin
```

`--data` 必须对应实际 Server 数据目录。密码按终端提示输入，长度要求为 12 至 1,024 字节。网页不提供“第一个访客注册管理员”的流程。

## 两步验证与 Passkey

在安全设置中添加并确认验证器动态码或 Passkey 后，会自动开启两步验证。密码登录后还需一种已添加的验证方式。

Passkey 需要 HTTPS 网页和兼容浏览器，并绑定注册时的域名。继续使用该域名登录；更换域名时需要在新地址添加 Passkey。Desktop 会引导你打开配置好的 HTTPS 网页进行设置。

“允许 Passkey 免密登录”是单独选项，默认关闭，至少有一个 Passkey 时才能开启。

## 保存恢复码与管理登录

启用登录保护后生成并妥善保存恢复码，每个只能使用一次，重新生成会使旧码失效。

“已登录设备”中可以查看和退出浏览器及 CLI 登录。默认登录有效期为 30 天；退出所有网页登录、修改密码或重置账号会让已有网页登录失效，但不影响 Desktop 身份或电脑连接。

## 无法登录时恢复

仍能打开 Desktop 时，可从安全设置处理。无桌面恢复入口时，在 Server 本机运行：

```sh
astral auth reset --data /path/to/server --username admin
```

这会重新设置网页登录，移除验证器与 Passkey，并退出所有网页登录；Bot、会话和已接入电脑会保留。没有邮件找回密码流程。

## 区分登录与电脑权限

网页登录保护管理入口。Bot 的电脑权限控制任务可以在哪些机器上执行；执行时仍使用电脑服务的操作系统权限。接入群聊前，确认这个 Bot 能访问的文件和工具适合该群的任务范围。
