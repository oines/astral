如果每次整理报告都要重复解释格式，可以把方法保存成一个技能。技能是一份工作说明，可以附带脚本或模板，供 Bot 在相关任务中使用。普通的一次性要求直接发在会话里即可。

如果要求只针对某个项目，例如“输出都放在 reports 目录”，可以放进这个项目的 `AGENTS.md`。技能侧重可复用的方法，项目说明侧重当前目录的约定。

## 使用内置技能

在运行新版 Daemon 的电脑上，可以请 Bot 把重复流程整理成技能、查找过去的 Astral 会话，或设置计划任务和本机事件唤醒。Server 会把相应的内置技能同步到电脑，首次同步后，Bot 就能发现它们。检索会话历史和调用 Computer API 时，所选电脑的**启用 Astral API**开关需要打开。随技能提供的 API 命令脚本使用 Python 3.8 或更新版本。

Astral 更新内置技能包时，会在原目录替换整套文件，覆盖本地改动。要保留改动，可以在更新前让 Bot 把修改后的版本另存为项目技能或用户技能。

## 放置一个技能

先确认会话使用的电脑和工作目录。技能文件要放在这台电脑上；可以自己创建，也可以让 Bot 帮你写入。

选择放置位置：

| 希望在哪里使用 | 技能目录的位置 |
| --- | --- |
| 这台电脑上、该系统用户的多个项目 | 用户主目录下的 `~/.agents/skills/` |
| 当前项目 | 当前工作目录下的 `.agents/skills/` |

每个技能有自己的文件夹，其中的说明文件必须叫 `SKILL.md`。例如，在当前工作目录创建 `.agents/skills/meeting-actions/SKILL.md`，内容如下：

```md
---
name: meeting-actions
description: 从会议记录整理待办事项、负责人和截止日期。
---

读取用户指定的会议记录。
按“事项、负责人、截止日期”整理表格。
没有明确写出的负责人和日期标为“待确认”。
保留原始记录，将结果另存为文件，并提供文件链接。
```

最上方两行 `---` 之间是技能信息：`name` 是名称，`description` 说明什么时候使用。两项都必须填写。后面的正文是具体做法；脚本和模板可以放在同一个技能目录中，并在说明里写清如何使用。

保存后，在会话中让 Bot 列出当前发现的技能，再尝试：

> 使用 meeting-actions 技能，整理我上传的会议记录。

检查它是否按约定生成了表格和文件。第三方技能可能附带会执行操作的脚本，使用前阅读来源、说明和代码；参阅[外来资料与技能](/zh-cn/docs/start/safe-use/#使用第三方资料或技能时)。

## 添加项目约定

在会话实际使用的工作目录放置 `AGENTS.md`。可以写项目用途、文件组织和需要遵守的工作方式，例如：

```md
# 项目说明

这是每周运营报告的工作目录。
原始资料保存在 input/，生成结果放在 reports/。
保留原始资料，不覆盖已有周报；新报告用日期命名。
引用数字时注明来自哪份资料，不确定的内容先标出来。
```

然后让 Bot 确认当前目录，并说明它读到的项目约定。

Astral 读取的是**当前工作目录中的 `AGENTS.md`**，不会自动向父目录查找。比如文件在 `/work/reports/AGENTS.md`，会话却工作在 `/work/reports/input/`，就需要回到项目目录，或在实际工作目录提供相应说明。

## 跨电脑使用

想让多台已连接的电脑使用同一份正式版本，可以请 Bot 创建或修改共享技能。先在当前电脑验证，确认这台电脑的[**启用 Astral API**](/zh-cn/docs/computers/connect/#控制电脑能否调用-astral-api)开关已打开，再明确请 Bot 发布。发布前，改动只在本机生效，这台电脑上的 Bot 共用这份文件。其他电脑同步后会收到发布版本，包括关闭了 Astral API 的电脑。

同步时，未修改的副本会在原目录更新。如果某台电脑有未发布的改动，系统会保留那台电脑的文件。可以请 Bot 对照本地文件和已发布的版本，把需要的改动整理在一起，再发布。其他共享技能照常更新。

项目技能和用户技能保留在本机。要在另一台电脑使用，请复制技能目录和所需的资源，并准备好它依赖的软件。

如果 Bot 没有发现技能，依次检查：

1. 会话选中的电脑和工作目录是否正确。
2. 文件是否位于上述技能目录，名称是否为 `SKILL.md`，运行电脑服务的系统账号是否能读取。
3. 文件开头是否有完整的 `---` 区域，以及非空的 `name` 和 `description`。
4. 电脑服务是否需要[更新](/zh-cn/docs/computers/connect/#更新已连接的-daemon)。

如果技能已被发现但不能执行，查看它要求的软件和文件是否都在当前电脑上，而不是只存在于另一台电脑。
