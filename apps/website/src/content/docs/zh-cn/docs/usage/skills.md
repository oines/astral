---
title: "技能与项目说明"
description: "让 Bot 发现电脑上的技能，并遵循当前项目的工作约定。"
---

技能是一组可复用的工作指导，保存在电脑上的文件中。Astral 从当前电脑发现可用技能，Bot 根据任务读取对应内容。

## 放置一个技能

在下列任一位置创建技能目录：

- 当前电脑用户目录下的 `~/.agents/skills/`：供该用户环境使用。
- 当前工作目录下的 `.agents/skills/`：供该项目使用。

例如，创建 `.agents/skills/project-review/SKILL.md`：

```md
---
name: project-review
description: 审查当前项目的改动，并列出需要验证的行为。
---

先阅读项目说明，再检查实际改动。
优先报告影响用户行为的问题，并注明文件位置和验证方法。
```

`name` 和 `description` 必须非空。技能需要的脚本和资源可以放在同一目录，并在说明中给出使用方式。

## 添加项目约定

在会话实际使用的工作目录中放置 `AGENTS.md`，描述项目结构、常用命令和工作约定。

Astral 读取的是**当前工作目录中的这个文件**，不会自动向父目录逐层查找。进入子目录后如果还需要原来的指导，应合理安排目录或在目标目录提供相应说明。

## 跨电脑使用

技能不会随着会话切换电脑而自动复制。需要在哪台电脑执行，就把技能及其依赖放到那台电脑。模型看到了技能说明，也不代表技能要求的软件已经安装。

如果技能没有被发现，检查会话当前电脑、工作目录、文件可读性、frontmatter，以及电脑服务版本。可以让 Bot 说明当前发现了哪些技能，帮助定位问题。
