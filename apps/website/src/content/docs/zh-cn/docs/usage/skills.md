如果每次整理报告都要重复交代同样的格式和步骤，把它存成一个**技能（Skill）**；如果约定只针对某个目录（如“输出放进 `reports/`”），放到该目录的 **`AGENTS.md`**。一次性要求直接发在会话里即可。

| 放什么 | 用哪个文件 | 作用域 |
| --- | --- | --- |
| 可复用的工作方法（可附带脚本、模板） | `SKILL.md` | 当前项目、本机用户，或发布为**共享技能**同步到全部电脑 |
| 当前目录的结构与规矩 | `AGENTS.md` | **仅限当前工作目录**（不向上查找父目录） |

## 使用内置技能

在运行新版 Daemon 的电脑上，Server 会自动同步内置技能——你可以直接请 Bot 把重复流程整理成技能、检索过去的 Astral 会话，或设置计划任务和本机事件唤醒。

:::note[调用 Astral API 的前提]
使用会话历史检索或 Computer API 时，需要打开该电脑的[**启用 Astral API**](/zh-cn/docs/computers/connect/#控制电脑能否调用-astral-api)开关；内置 API 辅助脚本需要 Python 3.8+。更新 Astral 时会覆盖内置技能目录的本地改动，想保留修改请另存为用户技能或项目技能。
:::

## 创建一个技能

先确认会话当前的电脑和目录（可以自己建，也可以直接让 Bot 写）：

- **仅当前项目用**：放到当前工作目录的 `.agents/skills/<技能名>/SKILL.md`
- **本机该用户的多个项目共用**：放到 `~/.agents/skills/<技能名>/SKILL.md`

例如创建 `.agents/skills/meeting-actions/SKILL.md`：

```md
---
name: meeting-actions
description: 从会议记录整理待办事项、负责人和截止日期。
---

读取用户指定的会议记录。
按“事项、负责人、截止日期”整理表格，未写明的标为“待确认”。
保留原始记录，另存为文件并提供文件链接。
```

开头 `---` 里的 `name` 和 `description` 必填（告诉 Bot 什么时候该用它），正文写具体做法，配套脚本或模板放进同一个文件夹。保存后让 Bot 列出已发现的技能并试跑一次：

> 使用 meeting-actions 技能，整理我上传的会议记录。

:::caution[使用第三方技能前先检查代码]
第三方技能可能附带可执行脚本，使用前务必检查来源、说明和脚本内容，详见[外来资料与技能](/zh-cn/docs/start/safe-use/#使用第三方资料或技能时)。
:::

## 添加项目说明（AGENTS.md）

在会话实际使用的工作目录放一个 `AGENTS.md`，写清项目背景和约束：

```md
# 项目说明

这是每周运营报告的工作目录。
原始资料在 input/，生成结果放到 reports/ 并用日期命名。
保留原始资料，数字须注明来源，不确定项先标出来。
```

放好后让 Bot 确认当前目录并复述它读到的约定。注意：如果文件在 `/work/reports/AGENTS.md`，会话却切进了子目录 `/work/reports/input/`，需要切回项目根目录或在当前目录放说明。

## 跨电脑同步：共享技能

想让一套经过验证的技能在多台电脑上保持一致，使用**共享技能**：

1. 让 Bot 创建或修改共享技能，先在当前电脑试跑验证（发布前改动只在本机生效）。
2. 确认当前电脑已打开[**启用 Astral API**](/zh-cn/docs/computers/connect/#控制电脑能否调用-astral-api)，再明确请 Bot **发布**。
3. 其他电脑同步后自动收到发布版本（包括关闭了 Astral API 的电脑；同步会替换整个技能目录，未发布的本地改动如需保留请复制到项目或用户技能目录）。
4. 要从所有电脑移除某个共享技能，在开启 Astral API 的电脑上请 Bot 按名称删除即可（离线电脑重连后自动清理）。

旧版电脑服务需先[更新 Daemon](/zh-cn/docs/computers/connect/#更新已连接的-daemon) 才支持这套发布与同步流程。普通项目技能和用户技能只留在当前电脑，跨机器使用需自行复制并备好依赖软件。

## Bot 没找到技能怎么查

1. 核对会话当前选中的电脑和工作目录。
2. 核对目录路径、文件名必须是 `SKILL.md`，且电脑服务的系统账号可读。
3. 核对文件开头有完整的 `---` 块及非空的 `name`、`description`。
4. 核对电脑 Daemon 是否需要[更新](/zh-cn/docs/computers/connect/#更新已连接的-daemon)；若技能可见但跑失败，确认依赖软件和文件都在**当前这台电脑**上。
