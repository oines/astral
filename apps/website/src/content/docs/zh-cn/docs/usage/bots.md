Bot 是你长期使用的助手：它有自己的名称和工作偏好，可以开展多个会话，也可以接入多个聊天账号。首次设置时已有一个名为 Astral 的 Bot，日常工作可以直接使用它。

需要不同的工作方式或信任范围时，再创建其他 Bot。例如，个人助手可以使用自己的工作电脑；面向公开群聊的 Bot 使用单独的容器和账号。仅仅想换个话题，可以[新建会话](/zh-cn/docs/usage/conversations/#把不同工作分开)。

## 基本设置

在主侧栏打开 Bot 切换菜单，选择**管理 Bot**，即可直接进入当前选中 Bot 的**基本设置**。也可以从**设置 → Bot → 目标 Bot → 基本设置**进入。

模型和搜索服务在[全局连接设置](/zh-cn/docs/usage/models/)维护，Bot 只需要选择要使用的资源。

删除搜索服务会关闭所有使用它的 Bot 的搜索服务，确认框会列出受影响的 Bot。已有会话和消息保留，之后可以再选择其他搜索服务。

人格说明适合写长期适用的工作偏好，例如：

> 你帮我整理日常工作。默认使用中文，先给可执行的建议。资料中没有写明的日期和负责人要标为待确认，不要自行补全。

填写后点击**应用人格**，该 Bot 所有会话的后续模型请求都会使用新说明，包括已经创建且正在工作的子代理；已冻结的请求保留原说明。清空后再次应用即可移除。应用人格不会启动空闲会话或子代理。开启群聊主动参与时，判断是否加入聊天也会参考当前人格。不需要额外偏好时可以留空。

## 模型不可用时继续工作

在**模型优先顺序**中，把希望新会话优先使用的模型放在第一项，再添加其他模型。每项分别保存自己的推理选项。请只加入你愿意用于同一任务的服务：切换模型继续工作时，会话和必要上下文也会发送给对应服务商。

拖动行左侧的手柄调整顺序；键盘聚焦手柄后，可以用上下方向键移动一项，或用 Home、End 移到顶部、底部。完成移动后会自动保存。

Astral 按列表顺序尝试。遇到额度、授权等需要换模型的错误时，跳到下一个可用候选；临时连接故障则在同一模型上最多尝试五次（含首次），耗尽后再换下一项。子代理使用相同的恢复规则。停用模型或连接后，列表保留原位置，执行时跳过。

修改列表会自动保存，也会更新已有会话可用的备用候选；各会话保留自己的首选模型。在会话输入区单独选择模型，就会把它设为该会话的首选。例如 Bot 列表是 A → B → C，手选 B 后按 B → A → C 尝试；手选列表外的 D，则按 D → A → B → C 尝试。

要让已有会话也以列表第一项为首选，点击**应用到未归档会话**并检查确认内容。操作覆盖此 Bot 未归档的会话及其子代理，替换各会话单独选择的首选模型；归档会话及其子代理保留封存时的选择，恢复后也不补改。已发出的请求按原模型完成，后续请求采用新首选；你主动停止的任务保持停止。

**自动恢复首选模型**默认关闭。开启后，Astral 会定期向受影响会话自己的首选模型发起真实请求，成功后在下一个请求边界切回，检测可能产生模型费用。所有候选都失败时，任务会继续等待恢复，每次检测结束后间隔一分钟再试。关闭时，所有候选都无法继续便会停止并显示错误；修复连接、额度或模型选择后，再继续会话。之后才开启自动恢复，也需要先继续已失败的会话，不会自行重启过去失败的任务。

群聊判断模型仍然独立设置。选择跟随会话时，它使用该会话当时实际采用的模型。选定固定模型后，随时可在同一菜单改回**跟随 Session 当前模型**，推理设置也会一起跟随会话。

## 电脑权限

进入这个 Bot 的**电脑权限**页，也可以从聊天输入区的电脑菜单选择**管理电脑**直接到达。在这里允许它使用所需电脑，并按需设置默认电脑。默认选择用于新会话；已有会话可以另选已获准的电脑。

如果电脑还没接入，先按[连接电脑](/zh-cn/docs/computers/connect/)完成连接，再回来授权。授权后，Bot 可以按电脑服务所用系统账号的权限读写文件和执行命令。只授权这个 Bot 真正需要使用的电脑，尤其是在[接入群聊](/zh-cn/docs/start/safe-use/#接入群聊给群安排专用-bot)之前。

撤销默认电脑的权限，也会清空默认选择。需要继续在另一台电脑工作时，明确选择新的电脑。

## 平台与账号

要从聊天软件使用这个 Bot，在它的设置中选择**连接平台**，再选 Telegram、QQ、微信或飞书，并按[对应平台指南](/zh-cn/docs/chat/overview/)连接账号。

一个 Bot 可以接入多个账号。例如，同一个 Telegram 平台下可以有两个不同账号；它们分别保存连接凭据、启停状态、允许使用的聊天和会话绑定。

## 停用与删除

暂时不想让某个平台账号接收消息时，关闭那个账号即可保留已有记录。只想阻止 Bot 使用某台电脑时，撤销该电脑权限。

删除 Bot 适用于彻底移除这个助手。它会永久删除所属会话和计划任务、平台连接凭据，以及 Astral 留存的聊天数据。删除前保存需要保留的记录。

外部平台上的账号、聊天和消息，以及电脑上的工作文件，仍然保留；需要清理这些内容时，在它们各自的位置处理。
