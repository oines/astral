**Bot** 是你长期使用的助手，拥有独立的人格说明、模型列表、电脑权限和聊天账号。默认已有一个 **Astral** Bot，日常可以直接用它。

- **只是换个话题** → [新建会话](/zh-cn/docs/usage/conversations/#把不同工作分开)即可。
- **需要不同的风格或信任边界**（例如私人电脑助手 vs 公开群聊容器助手）→ 新建一个 Bot。

从主侧栏的 Bot 切换菜单选**管理 Bot**，或打开 **设置 → Bot → 目标 Bot** 进入配置。

## 基本设置与人格说明

模型连接与网页搜索在[全局设置](/zh-cn/docs/usage/models/)统一维护，这里只需勾选要用的服务。

**人格说明**用来写长期适用的工作习惯（不需要时留空即可），例如：

> 你帮我整理日常工作。默认使用中文，先给可执行的建议；资料里没写明的日期和负责人标为待确认，不要自行补全。

填完点**应用人格**，这个 Bot 后续的新请求（包括正在运行的子代理和群聊主动参与判断）都会采用新说明；清空后再次应用即可移除。

## 模型不可用时继续工作

在**基本设置 → 模型优先顺序**中，把首选模型排在最前面，下面放备用模型（每个模型可单独配推理选项，拖拽行左侧手柄即可调序并自动保存）。

:::note[只放你信任的模型服务]
切到备用模型时，当前会话和上下文会发往对应服务商。请确保列表里都是你愿意处理该任务的服务。
:::

- **怎么切换**：遇到额度不足、授权失效等错误时，立即换下一个可用候选；临时网络/服务故障会先重试再切下一项。子代理沿用同一规则。
- **单独给某个会话换模型**：在会话输入区选模型即可，它成为该会话的新首选，同时继续沿用 Bot 列表里的其他模型当备用（例如 Bot 列表 `A → B → C`，会话手选 `B` 后按 `B → A → C` 尝试；选列表外的 `D` 则按 `D → A → B → C`）。
- **批量统一首选**：想把当前所有未归档会话（含子代理）的首选都改成列表第一项，点**应用到未归档会话**。
- **自动恢复首选模型**（默认关闭）：开启后，切到备用模型时会定期探测首选模型是否恢复，恢复后自动切回（探测发真实请求，可能产生费用）；全失败时也会每隔 1 分钟重试等待恢复，而不是立刻报错停止。

- **重试策略**：临时连接故障在同一模型上最多尝试 5 次（含首次）后再切下一个候选。停用的模型或连接会留在列表中，执行时自动跳过。
- **归档会话与已发请求**：**应用到未归档会话**不影响已归档会话（即使之后恢复归档也保留原选择）；已发出的请求按原模型完成，你手动停止的任务保持停止。关闭自动恢复后因全部候选失败而停止的任务，稍后才打开自动恢复时不会自动重跑，需手动继续会话。
- **群聊判断模型**：默认**跟随当前会话模型**（包含自动切换后的模型与推理设置），也可单独指定固定模型并随时切回。
- **无障碍排序与删除搜索**：聚焦排序手柄可用上下方向键及 `Home` / `End` 调整顺序。删除全局搜索服务会关闭所有引用它的 Bot 的网页搜索，但保留会话与消息。

</details>

## 选择运行摘要模型

打开**基本设置 → 运行摘要模型**。默认**跟随当前会话模型**，摘要会使用实际执行任务的模型，包括自动切换后的备用模型，并采用最低可用推理档位。也可以为此 Bot 单独选择模型，或选**关闭**省去额外请求。

实时查看会话时，Astral 可能会将精简的任务和近期进展发送给摘要模型的服务商。请选用你愿意交给它处理这些信息的服务。三种模式都可以查看活动行和展开详情。

## 电脑权限

打开 Bot 的**电脑权限**页（或从会话输入区的电脑菜单点**管理电脑**），勾选允许它使用的电脑，按需指定新会话的**默认电脑**。

- 还没连上的机器，先看[连接电脑](/zh-cn/docs/computers/connect/)。
- 撤销默认电脑权限会同时清空默认项；公开群聊 Bot 请务必确认只勾选了专用机器或容器，详见[权限与隐私](/zh-cn/docs/start/safe-use/#接入群聊给群安排专用-bot)。

## 平台与账号

在 Bot 设置里点**连接平台**，按[接入聊天](/zh-cn/docs/chat/overview/)绑定 Telegram、QQ、微信或飞书账号。同一个 Bot 可挂多个账号（甚至同一平台的多个账号），各账号独立管理凭据、启停状态和允许的聊天。

## 通过 ACP 接入应用

在**基本设置 → ACP 接入**中复制 WebSocket 地址，并用接入应用或设备的名称创建令牌。关闭窗口前请先复制令牌。给每个应用单独建一个令牌，便于独立撤销。撤销后，使用该令牌的客户端会立即断开。

持有令牌的人可以读取此 Bot 的普通会话历史，也可以发起或停止工作。私密会话和已归档会话不开放。发放令牌前先确认这个 Bot 获准使用哪些电脑。[检查客户端兼容性并连接](/zh-cn/docs/hosting/acp/)。

## 停用与删除

- **暂时停收消息**：关闭对应平台账号即可，历史完整保留。
- **暂时禁止访问某台电脑**：在**电脑权限**里取消勾选。

:::caution[删除 Bot 不可撤销]
删除 Bot 会永久移除它的全部会话、计划任务、平台凭据和 Astral 留存的聊天数据，并断开使用其 ACP 令牌的客户端。请先保存重要记录。外部聊天平台上的消息和各台电脑里的工作文件不会被删除。
:::
