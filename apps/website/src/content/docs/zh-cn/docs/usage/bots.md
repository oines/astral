title: "配置 Bot"
description: "管理 Bot 的身份、模型、电脑权限与聊天账号。"
---

Bot 是长期使用的身份。它可以拥有多个会话、使用多台获准电脑，并连接多个聊天平台账号。

从 **设置中的 Bot 列表**进入具体 Bot。这里的设置属于当前 Bot，不会自动应用到其他 Bot。

## 基本设置

可以修改名称、头像、默认模型和搜索服务。人格说明用于描述身份、说话方式或工作偏好，填写后点击“应用人格”；它会从该 Bot 后续的模型请求开始生效。

开启群聊主动参与后，下一次参与判断也会带上当前 Bot 的人格，帮助判断它是否适合加入对话。

不需要人格设定时可以留空。模型连接和搜索连接在全局设置中维护，在 Bot 页面选择要使用哪一个。

## 电脑权限

在“电脑权限”中选择这个 Bot 可以使用的电脑，并设置新会话的默认电脑。全局电脑页负责接入与连接管理，这里负责授权。

授予权限意味着 Bot 可以通过该电脑的服务账号读写文件和执行命令。默认目录不会把访问范围限制在那个目录里。

## 平台与账号

在“连接平台”中选择 Telegram、QQ、微信或飞书。每个平台可以连接多个账号；每个账号分别保存凭据、启停状态、聊天访问范围和会话绑定。

修改一个账号的连接参数，需要点击该区域的“保存连接”。开启或关闭账号、修改聊天权限等操作具有各自的生效范围。

具体步骤见[接入聊天](/zh-cn/docs/chat/overview/)。

## 停用与删除

如果只是暂时不收消息，可以关闭对应平台账号，保留会话记录。

删除 Bot 会永久删除它的会话、平台连接凭据和 Astral 保存的聊天数据。外部平台上的账号、聊天及消息，以及电脑上的工作文件不会因此删除。执行前请确认需要保留的记录和文件已另外保存。
