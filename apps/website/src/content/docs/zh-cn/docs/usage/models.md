Bot 需要连接一个可用的模型服务才能开始工作。首次引导里的“模型”步骤与 **设置 → 模型** 是同一个界面。

## 1. 添加模型服务

进入 **设置 → 模型 → 添加**，按你的账号类型选择预置服务或**自定义服务商**：

| 界面方式 | 怎么填 |
| --- | --- |
| **API Key** | 在服务商开发者控制台创建 API Key 粘贴进来（有区域选项时选与密钥匹配的区域）。默认勾选**保存后自动导入模型**。 |
| **继续登录 / 连接账号** | 按提示在浏览器完成授权，自动加载该账号的可用模型目录。 |
| **自定义服务商** | 填服务方提供的 Base URL、接口协议与密钥；额外请求头或推理映射仅在服务文档明确要求时填写。 |

:::note[网络连通位置]
所有模型请求由 **Astral Server** 发起（桌面版是本机，独立部署则是服务器）。自建或内网模型地址必须能从 Server 所在机器访问到。
:::

### 列表里没有想要的模型？

先点**刷新模型目录**；如果服务不提供目录或需要手工加，点**添加模型**填入服务商 API 使用的**完整模型 ID**（注意区分 API ID 和网页展示名）。

若提示缺少参数，请按该模型官方文档准确填写：
- **上下文窗口**：单次请求容纳的对话、资料与输出总量（Token）。
- **最大输出 Token**：单次回复允许生成的上限。

## 2. 为 Bot 或会话选用模型

- **首次引导**：直接选中刚配置的模型，继续下一步选电脑。
- **日常调整**：到 **设置 → Bot → 目标 Bot → 基本设置 → 模型优先顺序** 排列首选和备用模型；也随时可在会话输入区单独切换当前会话的模型（详细恢复策略见[模型不可用时继续工作](/zh-cn/docs/usage/bots/#模型不可用时继续工作)）。

配置完模型和电脑后，发一条只读指令验收密钥、额度和工具调用是否都正常：

> 读取当前电脑的工作目录，列出文件名，不要修改任何文件，并告诉我你使用的电脑和目录。

:::tip[图片识别与推理档位]
- 若模型标记为不支持图片，请求会自动用文字占位替代图片继续处理文本；原图仍保存在历史里，换到支持图片的模型后可继续识别。
- 推理选项建议先沿用**继承模型默认**，跑通任务后再按需在模型编辑或会话里选具体档位（**接口默认**表示交给服务商自己决定）。
:::

## 3. 配置网页搜索（可选）

网页搜索与模型服务分开配置（模型 API Key 不会自动当搜索密钥）。

1. 打开 **设置 → 网页搜索** 添加服务，填入搜索服务商密钥或自托管地址（同样需从 Server 所在机器可达）。
2. 保存后用简单关键词（如 `Astral GitHub`）测试，确认能返回标题和链接。
3. 回到目标 Bot 的 **基本设置** 选中这条搜索连接，它才生效。

## 常见连接问题速查

| 现象 | 排查方向 |
| --- | --- |
| 保存了服务，但首次设置不能继续 | 回到模型列表，确认至少有一个模型已启用、参数完整，并在引导里选中它。 |
| 密钥无效或无权限 | 核对 Key 是否对应当前服务和区域，确认账号有该模型权限；账号登录方式可重新授权。 |
| 额度不足或限流 | 检查服务商额度，或在 Bot 优先列表里加入其他受信任的备用模型。 |
| 连接超时 / 地址不可达 | 检查 **Server 所在机器**的网络和 Base URL（本地浏览器能打开不代表 Server 能连上）。 |
| 能聊文字，但调用工具报错 | 确认所选模型和接口协议支持工具调用（Tool Use）。 |
| 搜索测试有结果，Bot 却搜不了 | 确认在该 Bot 的**基本设置**里选定了刚测试通过的搜索服务。 |

<summary>查看子代理模型覆盖、目录刷新、停用删除与群聊判断模型细则</summary>

- **会话切模型如何影响子代理**：在原会话输入区切换模型或推理设置，会同步覆盖该会话当前全部已有子代理（含更深层和曾单独指定模型的子代理）；已发请求按原设置完成，其他会话和普通分支不受影响。也可在原会话让 Bot 只调整某个指定子代理的模型（不连带下级，也不自动启动新一轮）。
- **刷新模型目录**：同步连接返回的最新列表，自动新增模型并移除不再列出的条目（包括手工添加的）；仍在列表中的模型保留你的手改参数。拉取失败保留旧列表；服务成功返回空目录则会清空。Codex 与 GitHub Copilot 目录来自已登录账号。
- **停用 vs 删除**：临时不用直接关闭模型或整条连接即可，优先列表保留位置并在执行时跳过；删掉模型或服务商后，即使重建同名项也不会自动修复旧选择，需在优先列表手动替换。历史记录始终保留。
- **群聊主动参与判断模型**：开启[群聊协作](/zh-cn/docs/chat/groups/)的主动参与时，默认用会话当前模型判断是否唤醒空闲 Bot，也可在 Bot 设置里单独指定模型（该模型只负责判断是否开始，不执行实际任务）。

</details>
