title: "模型与搜索"
description: "连接模型服务，选择 Bot 默认模型，并配置网页搜索。"
---

Astral 使用你提供的模型服务。模型连接由 Server 发起，因此服务地址、API 凭据和网络连通性都应以 Server 所在机器为准。

## 添加模型服务

1. 打开 **设置 → 模型**，添加服务。
2. 选择对应服务或兼容接口，填写地址和所需凭据。
3. 点击当前区域的“保存连接”，再获取或添加模型。
4. 在模型列表中确认要使用的模型，按实际能力配置推理等选项。

服务地址可达不代表模型有使用权限。若调用失败，分别检查 API Key、模型 ID、服务额度以及服务返回的错误。不要把浏览器能打开某个地址当成 Server 能访问它的证明。

## 选择使用范围

在 **设置 → Bot → 目标 Bot → 基本设置**选择默认模型。它用于新会话；已有会话可在输入区单独选择模型和可用的推理选项。

不同服务对推理参数和工具调用的支持不同，以该模型显示的选项和实际响应为准。

## 配置网页搜索

网页搜索是独立连接，不会因模型 API 配置成功而自动可用。

1. 打开 **设置 → 搜索**，选择搜索服务并填写连接信息。
2. 保存连接后，使用测试查询检查结果。
3. 到 Bot 的基本设置中选择该搜索服务。

修改测试区的查询不会改变 Bot 的配置；测试使用已保存的连接。自托管搜索地址同样需要从 Server 可达。

## 群聊的主动参与模型

开启[群聊主动参与](/zh-cn/docs/chat/groups/)后，Astral 会先判断普通消息是否需要回应。默认跟随会话模型，也可以为 Bot 指定单独的判断模型。它负责判断是否参与，不代替主模型执行任务。
