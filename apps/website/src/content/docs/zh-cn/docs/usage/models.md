---
title: "模型与搜索"
description: "连接模型服务，选择 Bot 默认模型，并配置网页搜索。"
---

Astral 使用你提供的模型服务。连接从 Server 发起，自定义地址需要能从 Server 所在机器访问。任务消息、读取的内容和工具结果会交给所选服务处理，详见[数据去向](/zh-cn/docs/start/safe-use/#了解数据会发送到哪里)。

## 添加模型服务

1. 打开 **设置 → 模型**，添加服务。
2. 选择预置服务或兼容接口，填写地址和所需凭据。
3. 点击当前区域的**保存连接**并获取模型目录。获取失败时可以重试，也可以手工添加模型 ID。
4. 在模型列表中确认要使用的模型，补全所需的上下文和最大输出限制。

## 为 Bot 或会话选择模型

在 **设置 → Bot → 目标 Bot → 基本设置**选择默认模型。它用于新会话；已有会话可在输入区单独选择模型和推理选项。

选好后，发一个小任务验证模型能否回复和使用工具。调用失败时，按错误信息检查 API Key、模型 ID、服务额度和 Server 的网络连接。

更换会话模型会用于后续请求。已经开始的请求先完成；请求准备和上下文压缩期间，选择控件暂时不可用。如果当前模型已移除、停用或配置不完整，可以直接换成其他可用模型，已有历史会保留。

## 配置网页搜索

1. 打开 **设置 → 网页搜索**，选择搜索服务并填写连接信息。
2. 保存连接后，使用测试查询检查结果。
3. 到 Bot 的基本设置中选择该搜索服务。

搜索服务需要单独配置。测试区使用已保存的连接，测试查询只用于这次检查。自托管搜索地址也需要从 Server 可达。

## 调整推理选项

模型编辑中可设置默认推理方式。会话可以继承模型默认、使用接口默认，或选择该模型支持的档位和预算。可用选项取决于模型与接口格式。

更换模型 ID 或接口格式后，检查推理选项是否仍然适用。你填写的设置会保留在草稿中；补全必填限制并通过校验后即可保存。

模型资料来自当前连接、公开的 models.dev 目录和你的手动配置。缺失的资料会留空，服务商返回的完整模型 ID 会原样用于调用。

## 刷新或移除模型

进入服务商的模型列表，点击**刷新模型目录**，与这条连接返回的目录同步。Codex 和 GitHub Copilot 使用已登录账号的目录。

- 新列出的模型会加入；目录中已移除的模型也会从 Astral 移除，包括手工添加或修改过的模型。
- 仍在目录中的模型保留你的修改；未经修改的模型更新推荐资料。
- 成功返回空目录会清空当前列表；获取失败或目录不完整时保留上次列表。

删除单个模型后，下次刷新可能重新加入它。删除服务商会同时移除这条连接下的模型；重新添加连接后，需要重新选择 Bot 或会话要使用的模型。

## 群聊的主动参与模型

开启[群聊主动参与](/zh-cn/docs/chat/groups/)后，Astral 用模型判断普通群消息是否需要唤醒空闲的 Bot。默认使用会话模型，也可以为 Bot 指定单独的判断模型。

Bot 工作时，由主模型直接读取新增聊天内容。参与判断模型只负责决定是否开始工作，任务仍由会话模型执行。
