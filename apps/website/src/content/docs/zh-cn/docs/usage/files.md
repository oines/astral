工作文件保存在执行任务的电脑上，文件链接记住来源。Bot 读取的文件内容可能进入模型上下文并发送给所选服务，见[数据去向](/zh-cn/docs/start/safe-use/#了解数据会发送到哪里)。

## 给 Bot 提供文件

在会话中选择电脑，再使用附件按钮上传资料。上传目标是这台电脑，不是官网或浏览器所在设备。也可以直接告诉 Bot 已连接电脑上的绝对文件路径。

让 Bot 先确认文件名、位置和任务要求，尤其是多个电脑都有相似目录时。

## 打开结果

Bot 返回文件链接后，可以打开预览或下载。图片可在会话中显示；其他格式是否能直接预览取决于文件类型。

打开原文件需要来源电脑在线、文件仍存在，且 Bot 仍有访问权限。重要文件请在来源电脑另行备份。

## 工作目录和共享范围

同一个 Bot 在同一台电脑上有一个默认工作目录，不同会话可能共享它。整理不同项目时可使用不同目录；需要限制访问范围时，使用独立系统账号或容器。

默认工作目录不是文件系统沙箱。Bot 能访问的范围取决于电脑服务账号的权限，而不只限于当前目录。

## 从聊天接收和发送文件

平台附件会保留来源信息，Bot 可在需要时读取或下载到电脑上。能否发送某种文件，还取决于平台权限、格式与限制。

聊天图片会先提供压缩预览，并保留原图引用。文字或细节看不清时，可以让 Bot 下载原图再读取。视频和普通文件按任务需要下载到电脑。

预览失败时，消息会标明图片暂不可用，并保留文字和附件来源。可以让 Bot 再次尝试下载，或重新提供文件。

需要把结果发到聊天平台时，明确要求“把生成的文件发回当前聊天”，再检查发送结果。

备份时要分别保存 Server 数据、电脑工作文件和容器数据，见[升级与备份](/zh-cn/docs/hosting/maintenance/)。
