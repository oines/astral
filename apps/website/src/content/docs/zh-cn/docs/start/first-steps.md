首次打开 Astral，界面会带你完成“模型”和“电脑”两步配置。你可以直接跟随引导；这页补充开始前需要准备的东西，以及如何确认已经能正常工作。

## 准备一个模型账号

Astral 使用你连接的模型服务来理解任务。先选择你已有使用权限的服务，确认它支持的连接方式：

- **API Key**：在该服务的开发者平台或控制台创建密钥，准备复制到 Astral。部分预置服务提供“获取 API Key”链接。模型权限、可用额度和费用由该服务管理。
- **账号登录**：如果 Astral 为这个服务提供登录入口，按界面提示授权即可。
- **自行运行的模型服务**：需要提供它的接口地址，以及它要求的密钥。地址要能从运行 Astral 的机器访问。

API Key 是给应用使用的密钥，不能用聊天网站的登录密码替代。已有聊天订阅能否用于 Astral，取决于所选服务的连接方式和账号权限。

服务连接后还要选定一个可用模型。列表为空或模型不可选时，按[连接模型与网页搜索](/zh-cn/docs/usage/models/)检查授权、额度或缺失的模型信息。

## 确认任务会在哪台电脑上执行

使用桌面版时，可以先选自己的电脑。使用浏览器访问服务器版时，**“Astral 所在机器”指服务器**；你笔记本上的文件需要上传，或[将笔记本接入](/zh-cn/docs/computers/connect/)后使用。

完成引导会授权当前 Bot 在所选电脑上读写文件和执行命令。第一次尝试使用测试资料即可；准备接入共享群聊时，先安排[专用 Bot 和独立环境](/zh-cn/docs/start/safe-use/#公开群聊使用独立环境)。

## 试一个容易检查的任务

进入聊天后，可以发送：

> 请告诉我你现在使用的是哪台电脑、工作目录在哪里，并列出该目录中的文件。先不要修改任何文件。

完成后，检查执行记录中的电脑名称，以及返回的目录和文件列表。空目录也可以正常返回。这一次同时确认了模型能理解请求、电脑能执行任务。

如果助手只给出文字回答，可以继续说“请实际使用电脑工具检查”。如果报错，按提示区分模型连接问题和电脑离线，再查看[排查问题](/zh-cn/docs/hosting/troubleshooting/)。

接着可以拿一份资料试试[文件处理](/zh-cn/docs/usage/files/)。QQ、飞书等[聊天平台接入](/zh-cn/docs/chat/overview/)可以等这个任务成功后再做。
