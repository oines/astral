---
title: "首次配置"
description: "连接模型、授权电脑，然后完成第一个任务。"
---

首次打开 Astral 时，会为你准备第一个 Bot。先连接模型，再选择它可以使用的电脑，不需要先接入聊天平台。

使用 Desktop 可以直接开始。如果通过浏览器访问 Server，需要先设置并登录[网页登录账户](/zh-cn/docs/hosting/security/)。

## 1. 连接模型

在“先连接一个模型”中选择模型服务，填写该服务要求的连接信息并保存，然后选定要使用的模型。服务连接与模型选择是两个步骤：保存了 API Key，并不意味着已经为 Bot 选好了模型。

可以选择模型服务提供的 API，也可以配置自己运行的兼容服务。填写自定义地址时，这个地址必须能从 **Astral Server 所在机器**访问。

## 2. 选择电脑

在“让 Astral 在哪台电脑上工作？”中选择一台在线电脑，或者接入服务所在机器、容器或其他机器。

点击“开始使用 Astral”会同时完成两件事：允许这个 Bot 在所选电脑上读写文件和执行命令，并把它设为新会话的默认电脑。之后可在 Bot 的“电脑权限”中调整。

通过浏览器访问时，“本机”指运行 Server 的机器，不是当前打开浏览器的设备。要使用浏览器所在电脑，需要另行接入它。

## 3. 验证一次完整执行

新建会话，发送一个小任务：

> 查看当前电脑和工作目录，列出目录中的文件；暂时不要修改文件。

检查执行记录中的电脑名称和返回结果。确认正常后，再让 Bot 处理实际项目或生成文件。

## 接下来可以做什么

- 在[模型与搜索](/zh-cn/docs/usage/models/)中增加模型或配置网页搜索。
- [连接更多电脑](/zh-cn/docs/computers/connect/)，并逐个授权。
- [接入聊天平台](/zh-cn/docs/chat/overview/)，从私聊或群聊交代任务。

设置中的普通选择和短文本会自动保存；连接凭据等多字段配置需要点击当前区域的“保存连接”。出现错误时先处理该区域提示，不必寻找全局保存按钮。
