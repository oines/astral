title: "完成第一个任务"
description: "准备好模型账号、选定执行电脑，用一个小任务确认 Astral 已正常工作。"
---

首次打开 Astral，界面会引导你完成两步配置：**连接模型**与**选择电脑**。直接跟着引导操作即可；这页帮你提前备齐所需信息，并用一个安全的小任务验证整条链路。

## 准备一个模型账号

模型服务负责理解和规划任务。挑一个你已有使用权限的服务，按连接方式提前准备好信息：

| 连接方式 | 你需要准备什么 |
| --- | --- |
| **API Key** | 到服务商的开发者控制台创建一个 API Key（注意：这是调用密钥，不是聊天网站的登录密码）。部分预置服务在界面中附带**获取 API Key** 入口。 |
| **账号登录** | 界面提供登录授权入口的服务，直接按提示跳转登录即可。 |
| **自行运行的模型服务** | 准备好 API 地址（Base URL）和所需密钥，确保运行 Astral 的机器能访问这个地址。 |

:::tip[别忘了选中一个具体模型]
保存模型服务后，还需要在列表里选定至少一个可用模型，引导才能进入下一步。如果列表为空或提示参数缺失，按[模型与网页搜索](/zh-cn/docs/usage/models/)排查。
:::

## 确认任务在哪台电脑执行

- **桌面版**：直接选你正在使用的这台电脑即可。
- **浏览器访问 Server 版**：界面里的“Astral 所在机器”**指的是服务器**，不是你手上的笔记本。想处理笔记本里的文件，可以先上传，或者稍后[把笔记本接入进来](/zh-cn/docs/computers/connect/)。

:::caution[关于首次授权与群聊隔离]
完成引导会授权默认 Bot 在所选电脑上读写文件与执行命令。第一次先用测试资料；如果打算接入公开群聊，请先按[公开群聊使用独立环境](/zh-cn/docs/start/safe-use/#公开群聊使用独立环境)准备专用 Bot 和容器。
:::

## 发一个只读小任务验收

进入对话界面后，直接发送：

> 请告诉我你现在使用的是哪台电脑、工作目录在哪里，并列出该目录中的文件。先不要修改任何文件。

检查两件事：
1. 展开执行记录，确认电脑名称和返回目录符合你的预期（空目录也是正常结果）。
2. 确认它**实际调用了电脑工具**，而不只是口头回答——如果只回复了文字，接着说一句“请实际使用电脑工具检查”。

这一步跑通，说明**模型连接**和**电脑执行**都已经就绪。如果报错，先看提示属于模型连接失败还是电脑离线，再查[排查问题](/zh-cn/docs/hosting/troubleshooting/)。
