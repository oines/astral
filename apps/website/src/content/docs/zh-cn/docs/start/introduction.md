Astral 是一个能直接使用电脑的开源个人 AI 助手。你像给同事交代事情一样说明目标，它可以读文件、跑命令、生成文档或修改代码，然后把结果交给你。

常见用法包括：

- **整理资料**：读取会议记录或零散文档，提炼待办、负责人与结论并另存为文件。
- **处理数据**：检查多份表格里的缺失项或异常值，生成汇总报告。
- **操作代码与环境**：读懂本地项目、修改代码、跑测试、查日志，直接用上你电脑里已有的命令行工具和脚本。
- **跨电脑与聊天协作**：在同一次对话里串联笔记本、台式机和服务器；或者直接在微信、QQ、飞书、Telegram 里发任务并收结果。

## 5 分钟跑通第一次任务

1. **[下载并安装桌面版](/zh-cn/docs/start/get-astral/)**：第一次体验推荐直接装桌面版，内置本地服务，打开就能配置。
2. **[准备模型并选定电脑](/zh-cn/docs/start/first-steps/)**：连上你已有的模型服务（API Key 或账号登录），再选中要让它使用的电脑。
3. **发一个容易核对的小任务**：比如列出某个文件夹的文件或整理一份文档副本，确认执行过程和结果符合预期。

:::note[模型需要自行连接]
Astral 提供 Agent 运行环境，不自带模型额度。你需要准备一个可用的模型服务账号，具体方式见[准备模型账号](/zh-cn/docs/start/first-steps/#准备一个模型账号)。
:::

## 先记住 3 个核心概念

| 概念 | 是什么 | 什么时候需要关心 |
| --- | --- | --- |
| **Bot** | 你配置好的助手，有自己的性格、模型列表、电脑权限和聊天账号。 | 首次启动已自带默认的 **Astral** Bot。需要把私人工作和公开群聊彻底隔离时，再[新建其他 Bot](/zh-cn/docs/usage/bots/)。 |
| **会话（Session）** | 你和 Bot 围绕一件事展开的连续对话，可跨多台电脑协作。 | 同一件事接着聊；换毫不相关的话题时新建一个会话即可。 |
| **电脑（Computer）** | 真正存放文件、运行命令的机器——可以是本机、其他电脑或 Docker 容器。 | 桌面版默认用本机；需要操作其他机器时再[连接另一台电脑](/zh-cn/docs/computers/connect/)。 |

## 下一步怎么玩

- **处理手头资料**：看[文件与结果](/zh-cn/docs/usage/files/)，上传文件或直接指定电脑路径。
- **把常用事自动化**：看[计划任务与事件唤醒](/zh-cn/docs/usage/schedules/)，定时汇总或由本机程序触发。
- **在手机和群里发任务**：看[接入聊天](/zh-cn/docs/chat/overview/)，接入 Telegram、QQ、微信或飞书。
- **让助手 24 小时在线**：看[选桌面版还是 Server](/zh-cn/docs/hosting/architecture/)，部署到长期运行的 Linux 服务器。

:::caution[使用真实文件前]
授权一台电脑后，Bot 可以按系统账号权限读写文件与执行命令。第一次尝试请先用资料副本；涉及敏感文件或共享群聊，先读[权限与隐私](/zh-cn/docs/start/safe-use/)。
:::
